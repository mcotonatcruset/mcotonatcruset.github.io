# mcotonatcruset.github.io

Interactive portfolio of Martí Cotonat Cruset, software developer (C#, .NET, SQL) from Girona.

A side-view 3D room built with Three.js and Vite: walk past the wardrobe (experience), the desk (about,
projects, contact), the 3D printer (CV and prints) and the terrace bonsai (skills). Hosted on GitHub Pages.

```bash
npm install
npm run dev
```
